## Tooling

- Prefers Tailwind CSS utility classes as the styling foundation over hand-written/pure CSS, explicitly because it makes custom styling easier. Confidence: 0.8
- Prefers Nuxt UI (Tailwind CSS–based component library) as the UI approach, theming its components, over hand-rolling a bespoke CSS design-token/component system. Confidence: 0.6
- Prefers developing against an already-running local PostgreSQL instance rather than Docker Compose or an embedded zero-setup database (e.g. PGlite). Confidence: 0.5
